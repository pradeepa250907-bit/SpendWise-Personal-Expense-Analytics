# SpendWise – Personal Expense Analytics System

## Project Overview
SpendWise is a Python-based personal expense analytics mini-project developed using Google Colab.

The project demonstrates how data analysis and visualization can be used to understand spending patterns, monitor budgets, and generate useful financial insights from sample transaction data.

## Features
- Expense dataset creation
- Category-wise expense analysis
- Total and average expense calculation
- Monthly budget monitoring
- Highest spending category identification
- Smart rule-based spending recommendations
- Daily spending trend analysis
- Data visualization using bar, pie and line charts
- CSV report generation

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib

## Project Results

Using the sample dataset:

- Total Expense: ₹4,650
- Average Expense: ₹465
- Monthly Budget: ₹5,000
- Remaining Budget: ₹350
- Highest Spending Category: Shopping

## Project Files

- `SpendWise_Expense_Analytics.ipynb` – Complete Python notebook.
- `SpendWise_Expense_Report.csv` – Sample expense dataset.

## How to Run

1. Download the notebook.
2. Open Google Colab.
3. Upload the `.ipynb` file.
4. Run all cells.
5. View the generated analysis and graphs.
